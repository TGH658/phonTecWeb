响应式显示说明
----------------
本网站采用同一网址自动适配不同设备：
- 手机端（小于 768 px）：保持原有沉浸式单栏手机界面与底部导航。
- 平板端（768–899 px）：扩展内容宽度，论文卡片自动调整为三列。
- 电脑端（900 px 及以上）：使用宽屏桌面布局、顶部居中导航、双栏教授简介与多列论文墙。
- 超宽屏：论文卡片最多自动扩展为五列。

部署时只需把整个文件夹上传至支持静态网站的服务器，同一个公开链接即可在手机和电脑上呈现对应布局。
